This is the empty spatvector without attributes (Variables) besides the id and name of the canton in one Language (German). Of course it contains the necessary polygon data for all cantons and some lakes (for reference). It is possible to use the Canton names (name) or their id number to allocate data to the polygons.

To wrangle geodata (spatVectors and spatRasters), tidyterra will be used here. This allows users to recycle concepts used in the dplyr and ggplot packages to add data using geo_label_repel () and to use facet_wrap () amongst others. The application of color schemes is simplified when ggplot2 is used. The library ggnewscale is used here, when multiple color / fill palettes are required.

First the Variable Name (called Attribute in terra) is changed from Deutsch to name. Here, the tidyterra Package comes into play, since dplyr::rename(Deutsch=name) does not work on spatVectors. Ktv is a Spatvector, not a data.frame or tibble.

Caution 
dplyr::rename(Deutsch=name)
ℹ Error occurred in the 1st layer. Caused by error: ! Objekt 'Englisch' nicht gefunden

This error is not helpful since it is not created by (tidy-) terra but by packages operating below it, where the error occurs. Here in base R. That makes debugging notoriously difficult. tidyterra::rename(Deutsch=name) has to be used instead. Here, the package (tidyterra) does not have to be specified explicitly. It will be noted for the sake of clarity hereinafter where meaningful

As a next step, the multi-language file (Kantonsnamen in Landessprachen.csv) is joined using tidyterra::left_join. Again it is the function from tidyterra and again tidyterra does not have to be specified.

To filter data, the sibling function of the dplyr::filter function being tidyterra::filter can be and even is automatically is used.

At the end of these operations we get an updated Ktv - variable as displayed above. Inputting the variable name (Ktv in this case) allows to glimpse at the data. glimpse(Ktv) does the same but outputs a slightly different format. As a result, we get the variables id Deutsch Französisch Italienisch Romanisch Englischinstead of id, name.

I will not claim that this makes sense, but the function tidyterra::summarise(m = mean(id))returns the mean id of the three selected cantons. It is 7.7.

tidyterra::drop_na()is an interesting function, since the geoms containing no values in the selected columns (= variables or attributes) are dropped and the map is shrinked accordingly. This is true for other functions reducing the number of rows.
